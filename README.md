# Shioriko

AndroidスマートフォンをmacOSのFinderにボリュームとしてマウントする、メニューバー常駐アプリです。Windowsでスマホを接続したときに、ドライブとして表示されるのと同じ感覚で使えます。

スマホを**「ファイル転送 (MTP)」モード**で接続すると、ShiorikoがMTPセッションを開き、デバイスをローカル専用のWebDAVサーバー経由で公開して、`/Volumes/<機種名>` にマウントします。スマホはFinderのサイドバー「場所」に表示され、通常のディスクと同じようにドラッグ&ドロップでファイルの閲覧・コピー・リネーム・削除ができます。ケーブルを抜けばボリュームは消えます。

メニューバーのアイコンから、接続状態・ストレージの空き容量・転送速度の確認、Finderで開く、取り出し、自動マウントの一時停止などを操作できます。Dockには表示されません。

Shiorikoは単一のGoプログラム（メニューバーUIはcgo経由のAppKit）です。MTP (Media Transfer Protocol) でUSB越しに直接スマホと通信するため、Android File Transfer・adb・その他のGoogle製ソフトウェアは不要です。`Shioriko.app` には `libusb` が同梱されているので、実行時にHomebrewも不要です。

## しくみ

```
 Androidスマホ ──USB(MTP)──► libusb ──► internal/mtpdev ──► internal/davfs
                                                                  │
                                                       127.0.0.1 上のWebDAV
                                                                  │
                                                 macOS mount_webdav / NetAuthAgent
                                                                  │
                                                     /Volumes/<機種名>  ──► Finder

 internal/service（接続〜マウント〜取り外しの状態管理）──状態・イベント──► internal/menubar（メニューバーUI）
```

- `internal/mtp` — [`go-mtpfs/mtp`](https://github.com/hanwen/go-mtpfs)（New BSDライセンス）を同梱し、リカバリー用のヘルパー（PTPキャンセル、エンドポイントのドレイン）とUSB上の位置の取得を追加した改変版。
- `internal/mtpdev` — 並行アクセス安全なラッパー。エラーの正規化、切断検知、タイムアウトしたトランザクションの再試行、転送量の計測を行い、macOSではUSBインターフェースを取得するためにシステムの `ptpcamerad` デーモンを退避させます。
- `internal/davfs` — MTPのオブジェクトツリーを `webdav.FileSystem` インターフェースにマッピングします。短命なディレクトリキャッシュと、アップロード時の一時ファイルへのスプールを備えています。
- `internal/mount` — ファイルシステムをランダムなループバックポートで公開し、Finderに見えるボリュームとして `/Volumes` にマウントします。異常終了で残ったボリュームの後始末も行います。
- `internal/service` — USBを監視し、接続時に自動マウント、切断・取り出し時にアンマウントする状態機械。状態（待機中・使用中・接続中・マウント中・取り出し済み・一時停止・エラー）とイベントをUIへ通知します。
- `internal/menubar` — メニューバーUI。Go側で表示内容を組み立て、AppKit（Objective-C）側でステータス項目とメニューを描画します。
- `cmd/shioriko` — アプリ本体。既定ではメニューバーアプリとして、`-headless` でターミナル常駐プログラムとして動きます。
- `cmd/shioriko-probe` — 機種情報・ストレージ・ディレクトリ一覧を表示する診断ツール。

## 動作要件

- macOS（macOS 26 / Apple Silicon で動作確認）。同梱する `libusb` がビルドしたMacのmacOS向けにビルドされているため、アプリの最小動作バージョンはビルドしたMacのメジャーバージョンになります。
- ビルドには [Homebrew](https://brew.sh) の `libusb`・`go`・`pkg-config` と、Xcode コマンドラインツール（clang）が必要です。

```sh
brew install libusb go pkg-config
xcode-select --install   # 未導入の場合のみ
```

## ビルドとインストール

```sh
make            # build/Shioriko.app と bin/shioriko・bin/shioriko-probe をビルド
make install    # ~/Applications/Shioriko.app と ~/.local/bin にコピー
open ~/Applications/Shioriko.app
```

`make app` でアプリだけ、`make dist` で他のMacへコピーするためのzip（`build/Shioriko-<版>.zip`）を作れます。アプリはアドホック署名なので、ビルドしたMacではそのまま起動できます。他のMacで使う場合は、Developer ID で署名して（`make dist SIGN_IDENTITY="Developer ID Application: ..."`。Hardened Runtime とタイムスタンプ付きで署名します）`xcrun notarytool` で公証するか、受け取った側で「このまま開く」を許可してください。

## 使い方

スマホを**「ファイル転送 (MTP)」モード**にして接続します（スマホの通知バーからUSB通知を開いて選択します。機種によっては 設定 ▸ 接続済みのデバイス ▸ USB にあります）。数秒で `/Volumes/<機種名>` にマウントされ、Finderで開きます。

### メニューバーのアイコン

| アイコン | 状態 |
| --- | --- |
| スマホ（薄い表示） | スマホを待っている（未接続・「ファイル転送」以外のモード）／取り出し済み |
| スマホ | マウント中 |
| スマホ＋電波 | 接続中・取り出し中、またはファイルを転送中 |
| スマホ＋！ | スマホが他のアプリで使用中、またはマウントに失敗（自動で再試行します） |
| スマホに斜線 | 自動マウントを一時停止中 |

### メニュー

- **ヘッダ** — 接続中の機種名とマウント先、各ストレージの空き容量（使用率バー）、転送中は読み込み／書き込み速度を表示します。スマホがロック中でストレージが見えないときは、その旨を表示します。
- **Finderで開く**（⌘O）／**「機種名」を取り出す**（⌘E） — マウント中に表示されます。ファイルが使用中で取り出せないときは、強制的に取り出すか確認します。
- **「機種名」をマウント** — 取り出した後、ケーブルを挿したまま再びマウントします。エラー時は **今すぐ再試行** になります。
- **自動マウントを一時停止／再開** — 一時停止中はスマホに触れないので、写真アプリやイメージキャプチャからスマホを使えます。マウント中に一時停止すると取り出します。
- **設定** — 「マウントしたらFinderで開く」「接続と取り外しを通知」「ログイン時に起動」。
- **ログを表示…** — `~/Library/Logs/shioriko.log` をコンソールで開きます。
- **Shiorikoを終了**（⌘Q） — マウント中のボリュームを取り外してから終了します。

取り出し（Shiorikoのメニュー、またはFinderでのイジェクト）後は、ケーブルを挿し直すか「マウント」を選ぶまで、同じスマホを再マウントしません（ヘッドレス版では挿し直すとマウントします）。一時停止から再開したときは、接続中のスマホをマウントし直します。

### ログイン時に起動する

メニューの **設定 ▸ ログイン時に起動** をオンにします（システム設定の「一般 ▸ ログイン項目と機能拡張」に登録されます）。

### ターミナルから使う（ヘッドレス）

```sh
shioriko -headless          # メニューバーを使わずに常駐し、ログを標準エラーに出力
shioriko -headless -v       # 同上（詳細ログ付き）
shioriko -once              # 今接続中のデバイスをマウントし、抜いたら終了（-headless を含む）
shioriko -v                 # メニューバーアプリをターミナルから起動（ログもターミナルに表示）
```

ヘッドレスで常駐させたい場合は、ログイン時に `shioriko -headless` を起動する LaunchAgent を使えます（メニューバーアプリとは同時に使えません。アプリを起動すると、LaunchAgent を停止して切り替えるか確認します）。以前のバージョンでインストールした LaunchAgent から起動された場合も、自動的にヘッドレスで動きます。Ctrl-C（または SIGTERM）を2回送ると、転送の完了を待たずに終了します。

```sh
make autostart-install     # LaunchAgentをインストールし、即起動
make autostart-uninstall   # 削除
```

マウントせずにデバイスを確認する場合:

```sh
shioriko-probe            # 機種情報・ストレージ・トップ階層の一覧
shioriko-probe -read      # ファイルを1つ読み込んで速度も計測
```

## 注意点・制限事項

- **macOSの `ptpcamerad` について**: macOSはシステムデーモン `ptpcamerad`（イメージキャプチャの一部）を動かしており、スマホを接続した瞬間にすべてのPTP/MTP USBインターフェースを掴んでしまい、`libusb` からアクセスできなくなります。Shiorikoは接続のたびにこのデーモンを一度終了させてインターフェースを取得します。`launchd` がデーモンを再起動しますが、そのときにはShiorikoがインターフェースを保持しているため、デーモンはそのまま手を引きます。Shiorikoでマウント中は、イメージキャプチャや写真アプリの自動取り込みはそのスマホを認識できません（使いたいときは「自動マウントを一時停止」にしてください）。
- **同時に扱えるのは1台**: 複数のMTPデバイスを接続している場合は `-device <正規表現>` で1台を選びます（メーカー名・機種名・シリアルに対して照合します）。
- **Shiorikoは1つだけ起動できます**: メニューバーアプリとヘッドレス版は同時に動かせません。LaunchAgent（以前のバージョンのものを含む）が登録されている場合は、アプリの起動時に停止して切り替えるか確認します。
- **転送の中断**: スマホへのコピーが途中で中断された場合（強制的な取り出しなど）、そのファイルはスマホに書き込まず破棄します。
- **アップロードはスプール方式**: スマホへコピーするファイルは、まず `$TMPDIR/shioriko-spool` 以下の一時ファイルに書き出し、サイズを確定させてからデバイスへ送ります（MTPではサイズを事前に指定する必要があるため）。大きいファイルを扱うときは一時領域の空き容量に注意してください。一時ファイルは各転送後に削除されます。
- **上書き = 削除して再作成**: MTPには上書き保存の仕組みがないため、既存ファイルへの保存はそのオブジェクトを削除してから新しいオブジェクトを書き込みます。転送の失敗や途中終了で元のファイルを失わないよう、新しい内容はまず同じフォルダに隠しファイル `.shioriko-<ランダム>-<ファイル名>` として書き込み、転送が完了してから元のファイルを削除して本来の名前に変更します。途中で止まった場合は元のファイルが残り、この隠しファイルが残ることがあります（削除して構いません）。名前の変更に対応していないデバイスでは、元のファイルを削除したあと本来の名前でもう一度書き込みます（この場合は同じ内容を2回転送します）。
- **タイムスタンプ**: 表示される日時はデバイス側の更新日時で、ローカルのタイムゾーンで解釈されます。
- **異常終了したとき**: 強制終了などでボリュームが残った場合、次回の起動時に自動で取り外します。

## トラブルシューティング

- *いつまでも「スマホを待っています」のまま*: スマホを挿していても、ロック時や再接続時にUSBの用途が「充電のみ」に戻る機種があります。スマホが「充電のみ」や「USBテザリング」ではなく**「ファイル転送」モード**になっているか確認してください。スマホのロックも解除してください。
- *マウントされたが中身が空*: スマホのロックを解除し、「データへのアクセスを許可」の確認が出ていれば許可してください。
- *マウント後すぐに外れる*: 一部の機種は画面ロック時にMTP接続をリセットします。転送中は画面を点けたままにするか、ロックを一時的に無効にしてください。
- *「スマホが他のアプリで使用中です」と出る*: 別のプログラム（Android File Transfer、`adb`、イメージキャプチャ）がデバイスを掴んでいます。そのプログラムを終了してください（終了すると自動でマウントします）。
- *正常に抜けずに `/Volumes` にマウントが残った*: Shiorikoを起動し直すと取り外します。それでも残る場合は `diskutil unmount force /Volumes/<名前>` で外せます。
- *詳しい状況を知りたい*: メニューの「ログを表示…」、または `shioriko -v`（ターミナルから起動）で詳細ログを確認できます。
